DYNAMIC SOURCE LABELING SYSTEM
==================================================
Each extracted element was labeled with a dynamic source label following this pattern:

{PDF_filename}_pg{page_number}_{element_type}_{element_index}_{crop_name}_{issue_type}_{specific_name}_{additional_info}

Where:
- PDF_filename: Name of the original PDF file (without extension)
- pg{page_number}: Page number where the element is located
- element_type: Type of element (table or image)
- element_index: Sequential index of the element on that page
- crop_name: Name of the crop (when identified)
- issue_type: Type of issue (pest/disease/deficiency)
- specific_name: Specific name of the issue
- additional_info: Additional details (e.g., 'xref123' for images)
